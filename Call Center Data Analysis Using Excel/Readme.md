# Call Centre Performance Dashboard

## Overview
This project showcases a comprehensive **Call Centre Performance Dashboard** created using **Excel**. The dashboard provides a visual representation of call centre operations, including key performance indicators (KPIs), trends, and detailed insights into call data, employee performance, and customer satisfaction. 

---

## Features

### 1. Key Metrics
- **Total Calls:** 1,000 (Current Month: 207)
- **Revenue Generated:** $96,623 (Current Month: $20,372)
- **Total Call Duration:** 89,850 minutes (Current Month: 17,700 minutes)
- **Average Rating:** 3.9
- **Happy Clients:** 307 (60 this month)

### 2. Visual Components
#### **Call Trend Analysis**
- Yearly call volume trends to identify peak demand months.

#### **Day-Wise Call Distribution**
- Call volumes categorized by days of the week for resource optimization.

#### **Gender Ratio by Location**
- A visual breakdown of the **Women vs. Men Ratio** in:
  - Cincinnati
  - Cleveland
  - Columbus

#### **Customer Ratings**
- Distribution of ratings (1 to 5 stars), highlighting customer satisfaction.

#### **Performance by Representative**
- Key performance indicators (KPIs) for individual representatives (R01 to R05), including:
  - Number of calls handled
  - Revenue generated

### 3. Detailed Call Data
- City-wise and representative-wise performance analysis, including:
  - Call counts
  - Revenue contributions
  - Client IDs from each city

---

## Tools and Techniques Used

### Excel Tools
- **Pivot Tables**: To summarize and analyze data effectively.
- **Power Query**: For data cleaning, transformation, and preparation.
- **Conditional Formatting**: To highlight key insights.
- **Charts and Graphs**: For clear and impactful data visualization.
- **Data Validation**: To ensure accuracy and consistency of data entries.

### Analytical Techniques
- Trend analysis to identify seasonal call volume peaks.
- Comparative analysis of representatives' performance.
- Insights into customer demographics and satisfaction levels.

---

## Insights
- **Top Representative:** R03 leads in both call volume and revenue.
- **High Revenue Locations:** Columbus generates the most revenue.
- **Peak Performance Period:** October recorded the highest call volume, indicating increased customer demand.

## How to Use
1. Download the Excel file (`Call_Centre_Dashboard_Project.xlsx`).

3. Use the slicers and filters to drill down into specific data points.
4. Analyze the visualizations and metrics to derive actionable insights.
